# 曾建华（望楚居士）

扬州大学文学院副教授、硕士生导师，文学博士，研究方向为古典学与人工智能的交叉领域，聚焦先秦两汉思想史、名学与道家文献，同时关注 AI 时代的学术评价、知识组织与写作伦理。

> 本仓库同时面向两类读者：人可通过本页了解研究方向与在研课题；AI 助理可读取 [`AI_CONTEXT.md`](./AI_CONTEXT.md) 获取结构化的身份、研究偏好、成果清单与协作约定。

## 研究方向

- **先秦两汉思想与信仰**：道家与《道德经》《周易》、诸子文献、神仙观念的起源与演变。
- **名学与学术史**：先秦名学、明清名学史，概念与术语的源流梳理。
- **古典学 × 人工智能**：典故学理论、知识图谱与个人研究平台（子云平台 / 子云智网）的构建，AI 辅助古典文献整理与学术写作。
- **学术评价与伦理**：高校师德与评价制度、科研评价规范、AI 与学术写作的边界讨论。

## 方法与立场

- 考据优先：立论需可溯源，注明版本、篇目与可靠出处；古籍校勘尊重原文，不擅改字句。
- 对结论保持边界意识：证据不足处标注不确定性，不把推测写成定论。
- 写作追求雅俗共赏，避免套话、空话与机器腔。
